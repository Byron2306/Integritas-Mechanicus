## Development Failures That Became Proof

The strongest evidence chain includes the failures, because they show the evaluator was not rubber-stamping Sophia.

- A9 continuity/world-event ablation labels were crossed. They were corrected so each label removes the intended subsystem.
- The original denial proof contract required final release even when a case expected denial. The contract now branches for denial cases and measures correct refusal/hold behavior.

- The first unreparable denial run false-released because raw refusal was laundered into generic pedagogy. Sophia now preserves refusal semantics under unreparable covenant violations.

## What Is Not Yet Proven

- Longitudinal learner improvement is not proven. The stack is instrumented for ipsative and formative cycles, but the evidence does not yet show semester-scale human learning gains.
- Source-quality ranking is improved but not yet exhaustive. We still need explicit authority, recency, peer-review, conflict, and jurisdiction ranking tests.
- Production observability is partial. JSON artifacts and ledgers exist, but a dashboard-level telemetry chain for auditors would make the proof easier to inspect.
- External reproducibility is not complete. The evidence is local and artifact-backed, but third-party reruns with their own keys/environments would strengthen publication claims.
- Full matrix explosion has not been exhaustively run across every provider x every case x every mutation x every ablation x every fault because cost/latency would be significant. Focused high-risk slices are green.
