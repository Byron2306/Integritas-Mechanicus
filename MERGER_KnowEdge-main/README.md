# KnowEdge Merger V4.1 — Socratic Pulse

KnowEdge Merger is a high-fidelity forensic data synthesis engine designed for postgraduate research monitoring, academic integrity auditing, and autonomous task execution. Optimized for **NWU (North-West University)** standards and **SAQA NQF Level 9/10** descriptors.

## 🚀 Quick Start (Local Deployment)

1. **Install Stack**: Run `npm install` to load core dependencies (Vite, React, Tailwind).
2. **Configure Engine**: Create a `.env` file with your `GEMINI_API_KEY`.
3. **Launch Core**: Execute `npm run dev` and navigate to `http://localhost:3000` for immediate forensic access.

## 📱 Android PWA Installation

To use KnowEdge Merger on mobile for field research:
1. Open the application URL in **Chrome for Android**.
2. Tap the three-dot menu and select **"Install App"** or **"Add to Home Screen"**.
3. The app will now appear on your home screen as a standalone application, integrated with the **knowedge-merger-v4** service worker for stable background syncing.
